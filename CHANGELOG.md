# Change Log

All notable changes to this project will be documented in this file.

## [Unreleased]

## [1.0.0] - 2023-06-22

### Added

- Created a VS Code extension to interactively chat users about files.
- Ability to fetch file contents by asking the GPT-3 model.
- Ability to generate a file tree of the current repository.
- Rate limit handling for OpenAI's API with an exponential backoff strategy.
- The `getAPIKey` function to prompt users for their API key.

## [0.0.1] - 2023-06-01

### Added

- Initial project setup with npm and TypeScript.
- Basic structure of a VS Code extension.
